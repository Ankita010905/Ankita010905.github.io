Power System Analysis Using ETAP

Load-flow and short-circuit studies on an electrical network model.

The problem

Before a network is built or changed, an engineer needs to know whether bus voltages stay in range, how power flows, and how large the fault currents get.

What I built

  • Built an electrical network model in ETAP and studied performance under normal and fault conditions.
  • Ran load-flow analysis to evaluate bus voltages, power flows and system loading.
  • Ran short-circuit analysis to find fault-current levels at selected buses under different loading conditions.
  • Interpreted the results to understand system behaviour.
